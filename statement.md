# Project Statement

## Problem Statement
Students often maintain academic information and daily expenses separately. This project combines both tasks in one simple command-line Java application.

## Scope
Student records, expense records, summaries, reports and local file-based persistence.

## Target Users
Students.

## Functional Requirements
- Add, view, search, update and delete students.
- Add, view and delete expenses.
- Calculate category-wise expense summary.
- Calculate average CGPA and total expense.
- Save/load data using files.
- Generate a text report.

## Non-Functional Requirements
- Usability through a menu-driven interface.
- Reliability through validation and exception handling.
- Maintainability through modular classes.
- Resource efficiency through buffered file streams.

## Future Enhancements
JDBC/MySQL database, login system, graphical dashboard and PDF/CSV export.
